# ClipFlow Roadmap

## Phase 1: MVP

1. Create product specification and repository.
2. Build Twitch OAuth and clip detection.
3. Build clip download and audio extraction.
4. Add transcription and English captions.
5. Add FFmpeg 9:16 rendering with burned-in captions.
6. Build mobile review and approval screen.
7. Implement YouTube Shorts upload.
8. Add duplicate prevention and error handling.

## Phase 2: Kick support

1. Add Kick clip URL input.
2. Add Kick clip metadata extraction.
3. Add Kick clip download or capture workflow.
4. Add platform detection for Twitch and Kick.
5. Add Kick-specific duplicate prevention.

## Phase 3: More publishing

1. Add TikTok publishing after API approval.
2. Add Instagram Reels publishing after Meta API approval.
3. Add publishing status tracking.
4. Add retry logic and error notifications.

## Phase 4: Localization

1. Add Spanish captions.
2. Add Spanish UI localization.
3. Add language detection.
4. Add caption editing.

## Phase 5: Automation and growth

1. Enable fully automatic publishing mode.
2. Add scheduling.
3. Add performance analytics.
4. Add templates and caption styles.
5. Add team accounts and billing.
