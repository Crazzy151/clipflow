# ClipFlow mobile

This directory will contain the mobile-first ClipFlow client.

The MVP will use a responsive PWA so it can be installed on a Samsung Galaxy S21 without publishing to Google Play.

## Planned screens

- Login and Twitch connection
- Dashboard
- New clip list
- Clip detail and preview
- Caption editor
- Approval screen
- Publishing status
- Settings

## Core mobile flow

1. Connect a Twitch account.
2. View newly detected Twitch clips.
3. Paste a Kick clip URL when needed.
4. Review the generated 9:16 preview.
5. Edit captions if necessary.
6. Approve the clip.
7. Monitor YouTube Shorts upload status.

## Design principles

- Mobile-first layout
- Large touch targets
- Clear processing states
- Fast preview loading
- Minimal taps to approve and publish
- Clear error messages
